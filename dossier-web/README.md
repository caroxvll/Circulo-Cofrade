# Dossier web · Círculo Cofrade

Landing estática del dossier de colaboradores. **No forma parte de la app Flutter.**

## Ver en local

```bash
# Desde la carpeta dossier-web
npx --yes serve .
# o abre index.html en el navegador
```

También puedes arrastrar `index.html` al navegador.

## Contenido

- Portada estilo dossier (burdeos / oro)
- Colaborador: 129 € / mes · 297 € / trimestre
- Cupos: Buscar 10 · Calendario 5 · Foros 5
- Extras: foro y evento
- FAQ + contacto

## Despliegue

Sube solo esta carpeta a Netlify, Cloudflare Pages o una ruta del dominio (p. ej. `cofradeo.app/patrocinios`).

Sustituye `patrocinios@cofradeo.es` por el email/WhatsApp real en `index.html`.
