Simulación

Carga un mundo de prueba (usuarios, temas, respuestas, eventos) para ver la app en el móvil. El borrado solo elimina datos marcados como demo — tu admin real no se toca.

Usa esto solo en el proyecto pre (`env.pre.json`). En producción el flag `demo_tools_enabled` debe estar apagado.

Cargar simulación

~12 usuarios demo_*, 8 temas (1 pendiente), respuestas, likes, follows y 5 eventos. Si ya hay demo, la regenera.

Quitar simulación

Borra solo handles demo_*, temas demo-topic-* y emails @demo.cofradeo.local.

Verlo en el móvil

  1. Carga la simulación aquí.
  2. Arranca la app con pre: flutter run --dart-define-from-file=env.pre.json
  3. Entra con tu admin de pre (o explora foros/calendario).
  4. Cuando termines, pulsa «Quitar simulación».
